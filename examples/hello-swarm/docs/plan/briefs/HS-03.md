# HS-03: command line entry

## Objective
After HS-01 and HS-02 the package exports two functions, `greet(name)` from `src/greet.mjs`
and `farewell(name)` from `src/farewell.mjs`. Neither can be run from a terminal.

HS-03 adds `bin/hello.mjs`, which takes a name as its first argument and prints the greeting
then the farewell, one per line. It depends on both earlier tasks, so it starts only once
they have merged and the two functions have their final wording.

This task adds `bin/hello.mjs` and `test/cli.test.mjs`. It does not change either function,
nor the `bin` field in `package.json`, which nobody owns in this example.

## Read first
- `AGENTS.md`, all of it.
- `src/greet.mjs` and `src/farewell.mjs` as they stand on the base branch, for the exact
  wording to expect.
- `docs/plan/wps.json`: the HS-03 entry and its `deps`.

## You own

- `test/cli.test.mjs`

exact change rather than editing it.

## Hard rules for this task
- Read the wording from the merged source files. Do not reach for the strings in this brief
  or in the older tests.
- No dependencies. Node built-ins only, and `node:child_process` for the test.
- Do not edit `test/greet.test.mjs` or `test/farewell.test.mjs`.

## Work
1. `bin/hello.mjs`: read `process.argv[2]`, then print `greet(name)` and `farewell(name)` on
   separate lines. With no argument both fall back to `world`.
2. `test/cli.test.mjs`: run the entry point with `node:child_process` and assert the two
   lines, with a name and without one. Two tests.

## What "done" looks like
`scripts/skein/skein gate HS-03` ends `status=PASS`, and `node bin/hello.mjs Ada` prints the
greeting and the farewell for Ada.
