# HS-02: formal greeting

## Objective
`greet(name)` in `src/greet.mjs` returns `Hello, <name>!`, and `test/greet.test.mjs` asserts
that wording in three tests. The product wants a formal greeting instead.

HS-02 changes the wording and brings the tests with it. The three cases stay: a name, an
empty name, and no name at all. Only their expected values change.

This task owns `src/greet.mjs` and `test/greet.test.mjs` and changes nothing else.
`src/farewell.mjs` belongs to HS-01, which is running at the same time.

## Hard rules for this task
- **The three tests stay.** The new wording makes all three fail on the first run. Update each
  expected value. Do not delete a test, do not comment one out, and do not mark one as
  skipped or focused: the gate's `test-integrity` check counts the test declarations in
  `test/greet.test.mjs` and fails when the count falls, and it also fails on the tokens that
  switch a test off. A shared suite grows.
- No dependencies. Node built-ins and `node --test` only.

## Work
1. `src/greet.mjs`: `greet(name)` returns `Good day, <name>.` with a full stop. An empty name
   still falls back to `world`, so `greet("")` returns `Good day, world.`.
2. `test/greet.test.mjs`: keep all three tests and update the expected string in each. Rename
   a test's description if it reads better, but keep three separate declarations.
