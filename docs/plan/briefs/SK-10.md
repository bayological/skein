# SK-10: Swarm run log

## Objective
The docs run's evidence: `docs/swarm-run.md`, the coordinator's log of how a skein swarm built
this repository's docs, and one closing line in `README.md` that links it. The log covers the
setup, a timeline of every task, what the gate judged and what it could not, the cross-model
fact-check, the incident during SK-06, the kit bugs the run found, and the coordinator's own
mistakes. The coordinator writes it from the journal it kept during the run. It is never
dispatched.

The closing line is the one the owner approved in the coordinator session, word for word:
"This README, both diagrams, the example and the demo were built by a skein swarm working on
skein itself. [docs/swarm-run.md](docs/swarm-run.md) logs the run, fix rounds and mistakes
included."

## Read first
- `docs/plan/docs-run.md`, all of it.
- `docs/plan/LOG.md`, `docs/plan/reviews/docs-factcheck.md` and every brief in
  `docs/plan/briefs/`.

## You own
- `docs/swarm-run.md`
- `README.md`, for the closing line only

Nothing else.

## Hard rules for this task
- **Public repository:** no home path, user name, email address or credential; no employer or
  other project named (AGENTS.md rule 16); nothing from the owner's private notes.
- **Sources:** every time, count and finding traces to the journal, `docs/plan/LOG.md`, the
  pull requests or the fact-check table. Times are UTC, as in `docs/plan/LOG.md`.
- Writing rules (docs-run.md, rule 3); no em dashes; rule 17 for anything about the gate.
- The README change is the approved line above `MIT.` and nothing else.

## Work
1. Write `docs/swarm-run.md`.
2. Add the closing line above `MIT.` in `README.md`.
3. Run the gate on the task branch, push it and open the pull request. There is no worker
   worktree, so merge with `skein merge SK-10 --no-gate` once the CI gate check passes.

## What "done" looks like
`scripts/skein/skein gate SK-10` ends `status=PASS` on the branch, CI's gate check passes on the
pull request, and the README links the log.
