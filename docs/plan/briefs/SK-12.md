# SK-12: Example: one task per skein dispatch

## Objective
`examples/hello-swarm/README.md:111` says `skein dispatch HS-01 HS-02`. `skein dispatch` takes
one task per call: a second bare argument replaces the first (`commands/dispatch.sh:9-13`), so
that line dispatches HS-02 alone and says nothing about HS-01. The cross-model fact-check marked
it wrong (`docs/plan/reviews/docs-factcheck.md`, the `examples/hello-swarm/README.md:111-112`
row).

This task rewrites the sentence so each task gets its own call, the way `docs/demo/demo.tape`
does it. The kit stays as it is: whether dispatch should refuse a second task id is the owner's
call (ground rule 2).
