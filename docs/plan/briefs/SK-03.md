# SK-03: Task lifecycle diagram: SVG plus its source

## Objective
`README.md:55-64` shows how a task moves as a text block. This task draws the same flow as a
diagram, with the failure loop the text block cannot show: a hand-written SVG for GitHub's light
and dark themes, plus its source file. SK-04 places it under "How a task moves" next to the
existing block.

The flow, with labels taken from `docs/facts/FACTS.md`:
`/skein-brief` (brief and plan entry) → `skein dispatch` → `skein watch` → `skein gate` (worker)
→ `skein gate` (coordinator) → `skein review` (money/pii tasks only) → `skein merge`.
The failure loop: the gate fails → the worker fixes → the gate runs again. Show the loop from
both gate steps; the coordinator sends fixes with `skein send`.

Nothing else changes: no README edit (SK-04), no architecture diagram (SK-02).

## Hard rules for this task
- **Self-contained SVG:** no `<image>`, no `<script>`, no `<foreignObject>`, no external `href`,
  no web fonts. Text uses `font-family="ui-sans-serif, -apple-system, 'Segoe UI', Helvetica,
  Arial, sans-serif"`. Under 60,000 bytes.
- **Both GitHub themes:** a transparent background (no full-size background rectangle), box
  fills `none`, and every stroke and every text fill `#768390`. Neutral only: the two gate steps
  stand out by a 2.5px stroke, all other strokes are 1.5px; the failure loop is a dashed path.
- **Readable at 800px wide:** `width="800"` and a `viewBox` 800 units wide; body text 14px,
  titles 16px, nothing under 13px.
- **Same visual language as SK-02**, which runs at the same time: those exact colours, font,
  stroke widths and rounded boxes (`rx="6"`), so the two diagrams sit together in the README.
- Labels use FACTS.md's words and claim nothing FACTS.md does not say. No em dashes anywhere.
