# SK-02: Architecture diagram: SVG plus its source

## Objective
The README explains skein in prose alone (`README.md:1-64`); nothing shows how the pieces fit
together. This task draws one diagram of the whole system: a hand-written SVG that renders on
GitHub in both light and dark themes, plus a source file that says what it shows. SK-04 embeds
it near the top of the README.

The diagram shows, with labels taken from `docs/facts/FACTS.md`:
- the owner's checkout, with one or more coordinators;
- the board: GitHub issues, Superset tasks, or none;
- the plan: `docs/plan/wps.json` and the briefs;
- the driver: a Superset workspace or a local git worktree;
- workers running in parallel, each in its own worktree and branch;
- the gate, run by the worker, the coordinator and CI;
- cross-model review, for money and pii tasks only;
- the merge to the base branch.

Nothing else changes: no README edit (SK-04), no lifecycle diagram (SK-03).

## Read first
- `AGENTS.md`; `docs/plan/docs-run.md`, all of it.
- `docs/facts/FACTS.md`, all of it: every label comes from here.
- `README.md:1-64`, for the voice and the existing "How a task moves" block.

## You own
- `docs/assets/architecture.*`

That is `docs/assets/architecture.svg` and `docs/assets/architecture.md`. Nothing else. If a

## Hard rules for this task
- **Self-contained SVG:** no `<image>`, no `<script>`, no `<foreignObject>`, no external `href`,
  no web fonts. Text uses `font-family="ui-sans-serif, -apple-system, 'Segoe UI', Helvetica,
  Arial, sans-serif"`. Under 60,000 bytes.
- **Both GitHub themes:** a transparent background (no full-size background rectangle), box
  fills `none`, and every stroke and every text fill `#768390`, a mid-tone that reads on white
  and on GitHub's dark `#0d1117`. Neutral only: the gate stands out by a 2.5px stroke, all other
  strokes are 1.5px.
- **Readable at 800px wide:** `width="800"` and a `viewBox` 800 units wide; body text 14px,
  titles 16px, nothing under 13px.
- Labels use FACTS.md's words (`skein dispatch`, `wps.json`, `gate`) and claim nothing FACTS.md
  does not say. No em dashes anywhere.

## Work
1. Write `docs/assets/architecture.md`: a title, two sentences on what the diagram shows, a
   Mermaid `flowchart LR` with the same nodes and edges as the SVG, then a key that lists each
   node with the FACTS.md line it comes from.
2. Hand-write `docs/assets/architecture.svg` from it. Layout, left to right: the owner's
   checkout with its coordinators; the board and the plan beside them; `skein dispatch` through
   the driver into three parallel worker lanes, each lane showing its worktree and branch; each
   lane into the gate; the gate into cross-model review, labelled "money/pii only", and then
   the merge to the base branch. Mark that the coordinator and CI run the same gate.
3. Check it: `xmllint --noout docs/assets/architecture.svg`. Then preview it on both
   backgrounds: write two small HTML pages outside the repo (one white, one `#0d1117`) that
   embed the SVG, and screenshot each with `google-chrome --headless --screenshot
   --window-size=900,700`. Fix anything hard to read.
4. Run the gate.
